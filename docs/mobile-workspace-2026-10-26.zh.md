# 移动优先通讯工作区改造（2026-10-26）

基线：已部署 `cc46c90df2ec47240dad1d04b551b050321b9491`。本轮仅代码和本地测试，不部署、不修改账户/授权/真实群组。

## 改动

- 聊天优先：手机已有频道时首页改为紧凑会话行，弱化大图和卡片；聊天头、消息间隔、输入区收紧，44px 操作目标保留。频道详情中查看与管理分区，Agent 连接/管理默认折叠；任务保留状态切换，搜索与高级筛选按需展开。
- 输入区保持单行起步，随旋转/键盘可用高度重新计算，草稿不丢失；附件、上传和错误共用一个有界滚动区，不再各自叠高；附件操作展开为临时浮层。
- 删除旧实现按屏幕宽度重写 viewport meta 以及设置 document zoom 的行为。手机横竖屏统一紧凑布局；使用 visualViewport CSS 像素处理键盘，不重置用户 pinch zoom。适配低屏高和横屏安全区。
- 名单使用当前 identity API 元数据补齐 MCP 等非持续在线 agent；仍为离线，不把授权等同于在线，不复活已移除或纯历史身份。修复 agent 名字误被 owner/account 覆盖；当前昵称优先于历史 sender handle，消息与 @ 候选使用一致名字。
- 手机导航提供直接账户入口，复用原有账号/昵称/退出/安全设置，没有新增账户能力。
- 添加 Web App Manifest、Apple 主屏幕元数据及偏好设置内操作指南。支持 standalone 检测，不锁 orientation；不注册 Service Worker，不缓存私有接口，不宣称离线消息、原生 App、后台常驻或系统推送。
