## 已保留的核心加固

云端任务及 GitHub 发布使用每请求独立租约令牌，结果、错误、群消息回执与解锁
均校验当前所有者。获得锁后重新读取状态；撤销连接时原子清除凭据密文、撤销
群组令牌并作废在途租约。完成答案不会因为回执存储失败而降为未知态。
GitHub 写入前反复检查发布权限；未知远端结果必须恢复同一不可变提案。

此前审计与对照测试保留在 [并发加固记录](commons-hardening-2026-10-21.md)、
[群组与租约审查](commons-lease-review-2026-10-21.zh.md) 和历史验证文件中。
本补充分支没有重新改写生产源代码，而是在已合入实现上增加验证。

## 新增五项回归
