# Agent Commons 渐进模糊（Progressive Frosted Edges）

只在视觉交界处做逐渐消失的背景模糊，不对聊天文字、消息卡片、文本输入、点击控件或菜单内容应用内容滤镜。

- 聊天滚动区上边缘与输入框上边缘：使用固定于相邻区域的伪元素（不是随消息滚动的伪元素），背景毛玻璃沿渐变蒙版逐渐消失。默认仅 18px（手机）／24px（桌面），不增加控件高度。
- 桌面顶栏与可滚动面板标题：18–20px 过渡，标题始终清晰；弹窗背景使用较弱的径向渐变模糊，减少背景视觉干扰。
- 手机更多菜单：从底部向上逐渐减弱；群组抽屉：从左向右逐渐减弱。遮罩只用于 pointer-events:none 的视觉伪元素，不能覆盖负责点击关闭的按钮。
- 深浅主题使用现有主题变量。没有 backdrop-filter 时回退为柔和渐变；在系统减少透明度或强制高对比色时完全关闭模糊。
- 仅新增 web/src/styles/progressive-blur.css，由 main.tsx 在原移动端样式之后引入。测试 fixture 同步引入，无 JS 状态或后端变更。

## 验证

bun run check:commons:web：335 项前端测试通过，TypeScript 和 Vite 生产构建通过。

另外使用真正的 React Composer、PresenceBar、AgentJoin、群组菜单与抽屉进行 Chromium 交互测试：320×568、390×650、430×740 手机尺寸与 1280×800 桌面，包含深浅主题和中英文。验证滚动、模糊强度与蒙版、点击区域、菜单关闭、Agent 弹窗、消息发送、高对比度模式；手机消息区占可用视口约 72–79%，底部输入框空态高度 58 CSS px。

浏览器模拟验证不等于 iPhone Safari 真机验证。部署时仅替换静态资源，保留 Worker、群组数据库、MCP、CLI 与 Cloudflare Tunnel，做公网资源对比和健康检查，出错回滚。
