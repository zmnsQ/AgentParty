# OAuth 授权页与 Agent Commons 主站视觉统一

Agent Commons 作者：zmnsQ。基于原项目 AgentParty（郭立 / leeguoo 与贡献者）二次开发；保留 BUSL-1.1 与来源。

## 改动

此前授权同意页是独立的绿色圆角卡片，与主站的米纸底、等宽字体、墨线直角边框和硬偏移阴影不一致。

现在授权确认、重新确认及浏览器错误页使用同一个服务端模板与样式：

- 主站 Agent Commons 标识、米纸背景、珊瑚红主操作按钮、墨线卡片与硬阴影；CSS 颜色与字体变量从主站 `web/src/styles/tokens.css` 原样生成 `commons-theme.css`，不是另一套近似色值。
- 顶部呈现「登录账号 → 确认权限 → 返回插件」的步骤；突出友好群组名称及已登录 GitHub 名，内部群组 ID 放进可展开的详情。
- 仅展示本次实际可授予的读取、写入、事件权限；每项都有解释。显示批准后的准确回跳 hostname，但不输出完整回调参数。
- 失效、来源错误、需登录、需二步验证、群主权限或群策略不足等浏览器页面有统一的恢复说明，不再向用户直接显示裸 JSON；非 HTML API 请求保留原 JSON 与 HTTP 状态。
- 跟随主站主题及语言：`ap_theme`/`ap_locale` 仅是白名单化的非敏感首方显示偏好；不携带或改变认证信息。无偏好时采用主站默认纸色主题，语言仍可回退到浏览器设置。
- 320/390px 下为单列、48px 主操作目标；支持英文长名称、深色主题及键盘焦点。作者 zmnsQ、上游 AgentParty 作者与许可证清楚分开。

## 安全边界

页面仍是 **无脚本的服务端 HTML + 原生 POST 表单**。不增加 JavaScript、第三方字体、跟踪或外部图像请求，不开启 `unsafe-inline`。同源表单 Origin、仅本次已验证回调域名的 CSP、一次性 nonce、PKCE、已完成 MFA、群组策略、精确 redirect URI 匹配及批准/拒绝流程均保持。

成功批准仍直接 302 回到原插件；不插入假成功页，不要求额外确认，不延长授权有效期。只增加显示用的群名称读取，不迁移数据库，不更改用户授权或密钥。

## 实际验证

- `bun run check:commons`：691 项通过（53 HTTP + 281 Worker + 226 Web + 111 CLI + 4 配置 + 6 Muse SDK + 10 网络投递测试）；类型检查、Vite 构建及迁移编号检查通过。
- 构建后 `commons-theme.css` 与主站 tokens 源文件逐字节一致。
- 真实 Chrome Headless 渲染生产页面函数与实际样式，合成展示数据：中文/英文 × 纸色/深色 × 320/390/1280px × 首次确认/重新确认/错误，共 36 个场景，加 1 个超长名称场景，共 **37/37** 无整体横向溢出；操作按钮高度至少 48px。
- 复测原生浏览器表单在首次授权、过期后再次确认、同账号重新登录后三种情况下的跨站回跳。保留实际 `https://chatgpt.com` 回调 origin，外网访问前拦截并用隔离合成账号兑换；三条路径均返回 200，无跨站 Referer 泄漏。
- 上述不等于真实手机 Safari 全设备认证，也不创建或修改用户的个人 ChatGPT 订阅。
