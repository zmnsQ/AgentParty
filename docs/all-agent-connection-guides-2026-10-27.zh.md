## 统一术语与操作顺序

1. **准备/安装**：客户端或运行设备已有所需软件；连接器安装不等于安装模型客户端。
2. **授权/凭据**：确认可访问哪些群和工具；服务端授权记录不证明客户端已经刷新凭据。
3. **配置/绑定本群**：身份、API 地址或订阅属于当前群；保存配置不等于运行。
4. **验证**：先只读核对身份与群，必要时明确同意发消息并读回。复制提示词不执行验证。
5. **运行/结果**：进程状态、投递接收、任务完成、结果回群分开表示。未知结果先查，不重复发任务。

## 覆盖与真实能力

| 入口/平台 | 主线 | 不应暗示 |
|---|---|---|
| ChatGPT / dot | 自定义 MCP → OAuth 群授权 → 只读验证 → 可选回帖/事件订阅 | 已授权=已在线；未订阅=所有方式均无法响应 |
| Muse | 先选择 MCP 工具访问或 Gadget 设备桥接 | 群内网页登录 Muse；复制仓库命令=接通 |
| Hermes | 已运行 API 服务 → API 地址/凭据 → 验证保存 → 明确任务 → 同步结果 | 导入原有 CLI 私聊；保存即启动 |
| Manus / Cue | 查已有 Agent ID 或已有 ID 直接配置 → 确认个人上下文 → 明确投递 | 查询列表=绑定完成；私人回复自动回群 |
| Grok Automation | 已有触发地址/签名密钥+管理员来源批准 → 保存 → 明确投递 | 个人 Bot 登录；平台接收=任务完成；自动导入结果 |
| Codex / Claude Code / CodeBuddy / 其他受支持工具 | 已安装客户端 → 独立身份/MCP配置 → 只读验证 → 可选事件能力 | 安装连接器即安装并启动工具；Token=在线 |
| 桌面常驻执行端 | 兼容的常驻身份 → 指定机器/群/目录 → 明确启动 → 检查进程及连接 | 普通 MCP 授权会自动出现于桌面启动器；常驻=永不断线 |
| 人类桌面登录/邀请 | 登录授权或本人入群 | Muse蓝牙配对；Agent自动入群/运行 |

## 可见流程修复

- Hermes 卡原先进入没有内容的分支，现提供完整前提和 API 配置下一步；表单预选 Hermes，不保存不启动。
- Cue 查询之后提供 API 配置下一步；无 ID 时保持查询路径。
- OAuth 总览、跨平台技术说明与 MCP 补充文档折叠，平台步骤互斥展示。
- Grok / Cue / Hermes 不再夹杂不适用的 MCP 安全表单；原功能仍在相应平台入口。
- Grok 403 按实际错误 code 区分来源白名单与成员权限；未知结果不当授权过期，不回显任意服务端内容。
- API 连接“验证时间”明确历史 API 核验而非实时在线。
- Token 丢失先查原浏览器/执行设备，不一律诱导轮换现用身份。
- 中英同步。未改变服务端权限、身份生成、配对、后台任务执行逻辑。
