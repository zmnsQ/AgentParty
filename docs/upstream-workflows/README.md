# Archived upstream workflows

These files are the original upstream workflows from commit `25384eca99b24ed823ab54b4e850a0c9079a3b24`. They are preserved for attribution and architectural reference, outside `.github/workflows` so they cannot deploy to the original service or run the upstream's automatic reviewers and release matrix in this fork.

Commons has two manual workflows: a bounded Linux check and a single-platform desktop preview build. Neither publishes a release, deploys a service, submits comments, or triggers another workflow. See [the development guide](../commons-development.zh.md).
