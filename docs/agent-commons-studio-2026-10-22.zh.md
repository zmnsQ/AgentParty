## 实际改动

### 首页与导航

- 全局正文从终端式等宽字体切换到原生无衬线字体；代码和技术标识继续使用等宽字体。
- 温暖浅色与深色共享一套颜色、边界、阴影、间距、圆角和动效变量；保留旧主题偏好 ID，不清空设置。
- 首页提供明确的“新建群组”、按名称搜索、私有/公开标记和群卡片；用真实数据区分加载中、空列表和搜索无结果。
- 无消息群组提供可执行的“连接 Agent”入口，不再优先要求用户复制终端命令。
- 新建群组改为原生模态对话框：名字、可见性、折叠的高级选项。系统仍在服务端生成唯一 ID；关闭时焦点回到发起按钮。

### 对话与协作

- 消息使用更舒适的行宽、行高与代码块容器；本人消息与其他成员的消息有轻量视觉区别。
- 输入框主提示只描述发消息和 @，快捷键单独显示，手机端不堆砌说明。保留原有上传、提及和实时消息能力。
- 兼容中文输入法的 isComposing / keyCode 229，输入法确认不会被当成发送或关闭对话框。
- 协作空间默认先进入“连接与使用”；按平台选择，而不是先展示本地 Harness。
- API 直连 Agent 与 OAuth 插件明确分开。直连列表的零数量不再被误表述为所有平台都没有连接。
- 读取、回帖、日常任务、事件订阅步骤渐进展开；复制指令不是执行成功，权限允许也不是已订阅或 Agent 已在线。
- 保留作者、上游来源与许可证，作为清楚的页尾说明，不占据所有主要操作区。

### OAuth 授权与异常页

- 使用主站**同一个 tokens.css**构建公开样式，不再维护另一套不相关的颜色；通过非敏感、限值白名单的首方偏好 Cookie 同步语言与主题。
- 展示“登录账号 → 确认权限 → 返回插件”三阶段、可读群名、GitHub 名称、真实获批权限和返回客户端域名。
- 技术 ID 折叠；权限限制、允许/拒绝按钮和撤销说明始终可见，不自动勾选额外权限。
- 失效、未登录、MFA 未完成、群权限未开放等浏览器错误显示具体下一步；API 客户端仍返回原状态码和 JSON。
- 原生 POST、一次性 nonce、PKCE、MFA、精确回调 URI 匹配、允许当前已验证回调 origin 的 CSP 和 Referrer-Policy 保持原有保护。
- CSS 使用版本查询参数，避免已访问用户命中旧授权页样式。

## 交互与无障碍边界

按钮按下、菜单/面板进入、步骤展开和加载状态使用克制的短动效。尊重系统 reduced-motion；不播放默认提示音，不使用大幅位移或常亮装饰性闪烁。Tab 焦点、方向键切换、Esc 和原生对话框焦点约束保留。手机端重要按钮至少 44px，授权按钮至少 48px，输入框字号避免 iOS 聚焦自动缩放。

这不是全站 WCAG 认证或真实 iPhone/Android/原生 macOS/Windows 的完整设备验收。浏览器截图使用真实组件及合成 API 数据，不能当作真实用户群记录、授权记录或个人 Agent 实际在线的证明。

## 发布限制

仅更新 Web 静态资源和 Worker 的授权页呈现。没有数据库迁移；不更换 GitHub 应用、不重置 OAuth、Token、MFA 或事件服务内部凭据；不修改群组权限，不创建真实订阅或群消息。原生桌面安装包不在此轮发布范围内。

验证结果和部署版本在同轮验收记录中归档。发布前检查原有事件投递服务、OAuth 登录、匿名访问限制和新样式资源，失败则回滚程序，不把数据库恢复到过去时间点。
