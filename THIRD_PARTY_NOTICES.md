- Project: https://github.com/Caho1/open-claude-ui
- Author: Caho1; Copyright (c) 2026 Caho1.
- Reference revision: `c1f923ae0051a871941b98a0e2e3183a545e6a85`.
- License: MIT. Full original notice: [licenses/open-claude-ui-MIT.txt](licenses/open-claude-ui-MIT.txt).

The Agent Commons Studio refresh draws design inspiration from the reference's layered surfaces, typography hierarchy, restrained motion, progressive disclosure and input-method safeguards. The application uses its own React components and tokens and has not added the reference package as a runtime dependency. This reference is a community project, not an official Anthropic design certification or affiliation.

No Claude logo, proprietary typeface, voice asset or desktop bundle was imported. Interface icons are original inline line drawings; interface fonts use native system fallbacks, with the existing open-source code font retained for code.
